Repair plan and to-do

NowPlaying for Plex · 23 November 2026

Start with the release blockers. Repair packaging, credential handling and server changes in parallel. Then combine the playback and window fixes, run the regression suite, and inspect the bundle produced by the release build.

To-do

  1. Package into a private staging folder and detach only the disk image device created by that run.

    Exercise successful packaging and cleanup after an injected failure.

  2. Build a Developer ID signing and notarization path and replace the quarantine workaround in the install guide.

    Verify the release flow in isolation. A real signed release needs Apple credentials and a separate release check.

  3. Protect Plex credentials in Keychain in all builds, require HTTPS for remote endpoints, and make local HTTP an explicit choice.

    Test URL policy, redirect boundaries and credential migration with fixtures.

  4. Keep the current Plex connection until the replacement validates and saves. Restore the working view on Cancel.

    Test failed writes and the cancel path. Confirm the active configuration persists.

  5. Choose a playing music session consistently and let the user select a playback source.

    Test playing versus paused, reordered responses and a preferred source that has stopped.

  6. Have setup and polling use the same Plex response validation.

    Distinguish valid empty sessions from unrelated or invalid responses.

  7. Cancel stale artwork work and prevent old images from replacing the current cover.

    Test out-of-order completion, idle playback and an image load failure.

  8. Make settings keyboard reachable and return focus on dismissal.

    Check the window can become key and include Tab and Escape in the desktop smoke test.

  9. Keep the widget visible after monitor and layout changes and add Reset Position.

    Test saved coordinates on missing and secondary displays.

  10. Use Xcode for bundle versions and include the privacy manifest.

    Inspect the built bundle’s metadata, resources and both architecture slices.

  11. Retire the unsupported Electron prototype and ignore local credentials from older checkouts.

    Confirm the old entry point is gone and the credential file is excluded from Git.

  12. Add a macOS build and test job with packaging and bundle checks. Align the build and contribution docs.

    Run the checks locally where available and keep hosted CI status explicit.

Release check

Check the app on a clean Mac with a Plex server, including the menu keyboard flow and a second display. Verify signing, notarization and launch from the exact DMG before publishing.
