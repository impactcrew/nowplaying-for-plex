## What's new in 1.3.1

- Drag the widget and the setup window again. **Reset Position** is now beside **Layout Style** in settings.
- If several people are playing music on your Plex server, **Playback Source** lets you follow a specific user or device. **Automatic** picks a music session for you.
- Your saved Plex connection stays in place if a server change fails. Connections use HTTPS by default. For a trusted local server that needs HTTP, enable **Allow HTTP on my local network** during setup.
- NowPlaying for Plex has a five-bar Amber app icon, a matching menu bar icon, and a redesigned drag-to-install window.

## Installation

Open `NowPlaying-for-Plex.dmg` and drag **NowPlaying for Plex** into **Applications**. This version is built for Apple Silicon and Intel Macs running macOS 13 or later.

If you're upgrading directly from **v1.0.0**, enter your Plex server address and token again when setup opens.
