Hostile repo review

NowPlaying for Plex · 23 November 2026 · 2674137

Hold the next release. The packaging script can interfere with the build Mac, the install guide asks customers to remove a system protection, and a cancelled server change costs the user their working connection.

Release blockers

The installer script can eject a disk it doesn’t own.

The first disk operation forcibly detaches a hard-coded device before the script creates or mounts its own image. The script also changes your Finder preference for hidden files, kills Finder and only detaches its own image on the normal path. A packaging failure can interrupt unrelated work and leave the image mounted.

Repair. Use a unique staging directory, track the device returned by the attach call, and clean up only that device on exit. Keep Finder preferences out of the build.

create-dmg.sh 4–7 / 55–58 / 104–106 / 187–202

The download instructions make customers do release engineering.

The checked-in build signs ad hoc. The image script packages that result without a notarization step. The README asks customers to remove download quarantine with administrator privileges and describes that as enabling network access. The documented path cannot produce a normally trusted direct-download build.

Repair. Produce a Developer ID-signed, notarized release artifact for direct download. Verify the exact downloadable image on a clean Mac before rewriting the install instructions.

build.sh 69–83 / README.md 40–60 / Apple’s notarization requirements

The connection advice puts the Plex token on the wire in cleartext.

Setup accepts remote HTTP, advises an HTTP retry after an SSL connection failure, and sends the Plex credential in every session and artwork request. Loopback is a distinct case. A remote HTTP connection offers no transport protection for that credential. Debug builds also keep the token in ordinary preferences even though the contributor guide tells people to test against their own servers.

Repair. Default remote connections to HTTPS and explain how to fix certificate errors. Make local HTTP an explicit choice and use Keychain or disposable test credentials in development.

OnboardingView.swift 307–323 / 401–412, 445–448 / PlexAPI.swift 124–128, 202–209 / Config.swift 23–47 / CONTRIBUTING.md 152–159

Change Server deletes the working connection before testing the new one.

Reset discards the stored URL and Keychain token before opening setup. Closing setup then quits the app. On the next launch, the user has to set up Plex again. The Keychain write also deletes the prior item before attempting the replacement.

Repair. Validate replacement credentials while the old connection stays active. Update the stored credential only after validation succeeds, and return to the existing widget on Cancel.

Fix next

The widget shows whichever listener Plex lists first.

Plex’s sessions endpoint lists current playbacks across the server. The app takes the first eligible music session with no user or player selection. A paused session can beat a later playing one, and a shared server can put another listener’s track on this Mac. The product description also says Plex media while the implementation selects music tracks only.

Repair. Define whose playback the widget follows. Filter by the selected user or player, prefer a playing session and use a stable tie-breaker. Say music in the product description if music is the scope.

PlexAPI.swift 139–147 / README.md 12–14 / Plex List Sessions API

Setup treats any HTTP 200 as a working Plex connection.

Onboarding discards the response body and accepts status 200. A proxy or sign-in page can therefore complete setup, while the playback poll immediately fails trying to decode it as JSON. A shared endpoint check would also prevent drift between onboarding and playback.

Repair. Use the same request and response validation in setup and polling. Require a valid Plex sessions container and accept an empty session list.

OnboardingView.swift 401–423 / PlexAPI.swift 117–146

A slow response can put yesterday’s cover on the current track.

Each artwork change starts an independent task. Any successful response can update the image, even after a newer cover has loaded or the player has gone idle. A failed image request can leave the old cover up indefinitely.

Repair. Tie the request to the current artwork URL, cancel superseded work and discard stale completions. Show placeholder art if the current request fails.

NowPlayingView.swift 645–677

The settings panel asks macOS for focus it cannot receive.

The panel is a plain borderless NSWindow. AppKit declines to make that window key, so normal keyboard navigation cannot reach its controls. This repo already has a window subclass that can receive focus and uses it for onboarding.

Repair. Use a key-capable settings window or a native popover. Verify that Tab reaches the controls and that dismissal returns focus to the menu bar item.

NowPlayingForPlexApp.swift 15–24, 279–304 / AppKit focus rules

The widget can stay parked on a display you unplugged.

Window positions are raw screen coordinates. On restart the app uses them without checking the current displays. Switching layouts also resizes around the old position without checking the visible area. An off-screen widget leaves the menu bar icon as the only clue that it is running.

Repair. Clamp the frame to an available display when restoring or resizing, recover when displays change, and offer a way to reset the position.

NowPlayingForPlexApp.swift 169–192, 242–263

The bundle contradicts its release label and drops its privacy manifest.

The project says 1.3.0 build 1 but uses a plist that hardcodes 1.2 build 3. Inspection of the older local bundle confirmed 1.2 build 3. The sole resources phase copies the asset catalog and omits the privacy manifest, which is also absent from that bundle.

Repair. Use the Xcode settings as the single version source, add the manifest to the target and check both in the finished artifact.

Info.plist 19–22 / project.pbxproj 143–152, 334–347 / Apple’s app bundle layout

The second app makes accidental credential commits easy.

The root package still launches the Electron prototype. It expects a plaintext Plex token in a root config file that Git does not ignore. It also puts the token in artwork URLs, where request logs can capture it. Its renderer has Node integration enabled and context isolation turned off.

Repair. Retire the prototype from the root if it has no owner. If it remains a supported entry point, give it secure credential storage, authenticated requests that keep the token out of URLs and an isolated renderer.

package.json 1–8 / renderer.js 128–146 / plex-api.js 49–55 / main.js 20–24

There is no automated check between a patch and a release.

The shared Xcode scheme has an empty test list. The tracked tree has no test suite or GitHub Actions workflow, and the root package has no test command. The contributor guide points at the wrong Xcode project and describes playback controls absent from the native widget. The README’s Xcode 15 / Swift 5.9 baseline predates syntax used in the current source.

Repair. Add fixture tests for session selection, invalid responses, failed server changes and out-of-order artwork. Add a build job and verify the final bundle. Publish a toolchain minimum you’ve tested and correct the contributor guide.

Repair order

Start with packaging and the documented download. Fix connection replacement and credentials together. Then test which session the widget chooses and what happens when setup, artwork or display changes go wrong. Put those checks in the release process before cutting another build.

What was checked. Native Swift source parsed with Xcode 27.2’s compiler. Shell and JavaScript syntax checks passed, as did the Xcode project and plist lint checks. The existing local bundle was inspected for version, architectures and resources. Git confirmed the legacy credential filename is unignored and the project has no tracked automated test suite.

Limits. The fresh unsigned arm64 build stopped when Xcode’s build service crashed in the sandbox. Verdicts on app behavior come from source and platform documentation. This review did not exercise a live Plex server, run the DMG script, or verify any published download.
