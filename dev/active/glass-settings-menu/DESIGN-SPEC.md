- Controls: subtle white neutral fills, standard launch switch, named color choices and selected-state checkmarks.
- Footer: keep Change Server directly beneath the address with the original four-point stack spacing. Do not add a minimum-height frame that shifts its text down.
- Accessibility: retain opaque background under Reduce Transparency, reduced animation under Reduce Motion, labels and selected-state traits.
- Hosting: retain the existing hosting window and its native size constraints; no clipping defect was demonstrated from the seeded height alone.
